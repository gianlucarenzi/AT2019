Benvenuto! Questo è il porting del RMT Player per Commodore 64.

I file RMT utilizzano un formato GENERICO a 3 canali che funziona su:
  ✅ Commodore 64 (SID - 3 canali)
  ✅ ATARI 8-bit (POKEY - 4 canali, 1 canale silenzioso per compatibilità)

═══════════════════════════════════════════════════════════════════════════════

🎮 COMPATIBILITÀ CROSS-PLATFORM

Il formato RMT generico a 3 canali permette lo stesso file musicale di suonare
sia su C64 che su ATARI con il medesimo risultato musicale.

ATARI:
  CH1: Melodia
  CH2: Armonia
  CH3: Effetti/Bassi
  CH4: SILENZIOSO (riservato per SIO)

C64 SID:
  CH1: Melodia
  CH2: Armonia
  CH3: Effetti/Bassi

🚀 QUICK START

1. Compila questo skeleton così com'è:
   
   $ cd rmt_cbm64
   $ make
   
   Risultato: build/rmt_cbm64.prg (executable C64)

2. Esegui con VICE (emulatore C64):
   
   $ make run

3. Per usare la tua canzone RMT:
   
   $ cp your_song.rmt music/
   $ make SONG=music/your_song.rmt

sid_play_off();            // Ferma la musica

🔧 TOOL DI CONVERSIONE

Per convertire un file RMT ATARI (4 canali) al formato generico C64 (3 canali):

  python3 tools/rmt2cbm64.py input.rmt output.rmt

Questo:
  • Legge il file RMT ATARI (4 canali)
  • Merge i canali 3+4 in un unico canale SID-compatibile
  • Genera un RMT a 3 canali ottimizzato per SID
  • Output è compatibile sia con C64 che con ATARI

❓ FAQ VELOCE

D: Cosa cambia tra ATARI e C64?
R: Solo il chip audio (POKEY vs SID) e i registri.
   I file RMT sono identici (3 canali). Il player adatta automaticamente.

D: Il file RMT ATARI a 4 canali funziona?
R: Sì, lo converte automaticamente a 3 canali (merge CH3+4).
   Usa: python3 tools/rmt2cbm64.py song.rmt song_3ch.rmt

D: Quale emulatore usi per testare?
R: VICE (Versatile Commodore Emulator)
   $ apt install vice
   $ make run

D: Come faccio a creare RMT su C64?
R: Usa Raster Music Tracker (originale ATARI software).
   Genera file a 3 canali, poi compilali con questo skeleton.
