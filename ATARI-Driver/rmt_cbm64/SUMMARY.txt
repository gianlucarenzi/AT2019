PANORAMICA
══════════════════════════════════════════════════════════════════════════════

Hai completato la creazione di **rmt_cbm64**, un player RMT completo per
Commodore 64 che suona musica RMT su SID usando un formato GENERICO a 3 canali.

Il progetto è modellato su RmtSkeleton (versione ATARI), ma adatto a C64.

CARATTERISTICHE TECNICHE
══════════════════════════════════════════════════════════════════════════════

✅ CORE PLAYER
   • Adattamento del player RMT originale (Radek Sterba / Raster C.P.U.)
   • Compilato con cc65 (ca65 assembler)
   • Target: Commodore 64 con chip SID

✅ TIMING (SINCRONIZZAZIONE)
   • CIA1 Timer A: genera ~50 Hz IRQ (PAL)
   • Player chiamato da IRQ handler
   • Frame counter per diagnostica

✅ SID SYNTH
   • 3 voci polifoniche
   • Registri SID mappati: $D400-$D41F
   • Control register, frequency LO/HI, ADSR, volume

✅ FORMATO RMT GENERICO
   • 3 canali (compatibile con SID C64)
   • Compatibile anche con POKEY ATARI (1 canale riservato a SIO)
   • Header: $FFFF seguito da dati pattern/instrument

✅ TOOLS
   • rmt2cbm64.py: Converte RMT binario → ca65 source code
   • Genera correttamente _rmt_song_data symbol (cc65 C-linkage)

API C (SEMPLICE)
══════════════════════════════════════════════════════════════════════════════

#include "sid.h"

void sid_init(const uint8_t *song_data);     // Inizializza
void sid_play_on(void);                      // Start playback
void sid_play_off(void);                     // Stop & silence

extern volatile unsigned int   sid_frames;   // Frame counter
extern volatile unsigned char  sid_status;   // 0=idle, 1=playing
extern volatile unsigned char  sid_volume[3]; // Volume per voce

CROSS-PLATFORM: ATARI + C64
══════════════════════════════════════════════════════════════════════════════

Con questo player, lo STESSO file RMT funziona su ENTRAMBI:

┌─ Commodore 64 ─────────────────┬─ ATARI 8-bit ──────────────────┐
│ SID (3 voci)                    │ POKEY (4 canali, 1 riservato)   │
│  CH1: Melodia          ✓        │  CH1: Melodia         ✓         │
│  CH2: Armonia          ✓        │  CH2: Armonia         ✓         │
│  CH3: Bassi/Effetti    ✓        │  CH3: Bassi/Effetti   ✓         │
│                                 │  CH4: [Riservato SIO] -         │
│                                 │                                 │
│  RISULTATO: 3 canali audio      │  RISULTATO: 3 canali (+ 0                 │
│             pieno               │  durante caricamento da disco)  │
└─────────────────────────────────┴─────────────────────────────────┘

Questo design permette:
  • STESSO file musicale su entrambi i sistemi
  • Nessun glitch audio su ATARI durante SIO (disco)
  • Profilo musicale identico

ARCHITETTURA DEL PLAYER
══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────┐
│                    COMMODORE 64                         │
│                                                         │
│  main.c (C)                                             │
│    │                                                    │
│    ├─ sid_init()  ──►  (sidplayer.s) _sid_init         │
│    ├─ sid_play_on()  ──► (sidvbi.s) _sid_play_on       │
│    └─ sid_play_off()  ──► (sidvbi.s) _sid_play_off     │
│                                                         │
│  CIA1 Timer A (50 Hz IRQ)                              │
│    │                                                    │
│    └─► IRQ Handler (sidvbi.s)                          │
│        ├─ Increment _sid_frames                        │
│        ├─ Call _sid_player() (sidplayer.s)             │
│        └─ Update SID registers ($D400-$D41F)           │
│                                                         │
│  SID Registers                                          │
│    ├─ Voice 1: $D400-$D406 (pitch, envelope, ctrl)    │
│    ├─ Voice 2: $D407-$D40D                             │
│    ├─ Voice 3: $D40E-$D414                             │
│    ├─ Filter:  $D415-$D417                             │
│    └─ Volume:  $D418                                   │
│                                                         │
└─────────────────────────────────────────────────────────┘

MEMORIA (C64)
══════════════════════════════════════════════════════════════════════════════

$0000-$00FF    Zero page (cc65 runtime + player vars)
$0100-$01FF    Stack
$0801          Load address (PRG header)
$0800-$9FFF    Program + Music data + Player (~40 KB)
$D400-$D41F    SID registers (I/O)
$E000-$FFFF    Kernal ROM

rmt_cbm64.prg size: ~2.9 KB
Spazio disponibile: ~37 KB per musica + codice aggiuntivo

DIFFERENZE RISPETTO A RMTSKELETON (ATARI)
══════════════════════════════════════════════════════════════════════════════

ATARI (RmtSkeleton):           C64 (RMT CBM64):
├─ POKEY chip (4 canali)       ├─ SID chip (3 canali)
├─ VVBLKI (immediate VBI)       ├─ CIA1 Timer A (IRQ)
├─ OS hardware registers        ├─ Custom SID registers
├─ 4 canali musica             ├─ 3 canali musica
│  (3 + 1 riservato SIO)        │  (tutti disponibili)
├─ Makefile: atari target       ├─ Makefile: c64 target
├─ Linker: rmtskeleton.cfg     ├─ Linker: rmt_cbm64.cfg (c64.cfg)
└─ ROM richiesta: ATARIXL.ROM  └─ No ROM richiesta

FORMATO RMT
══════════════════════════════════════════════════════════════════════════════

Header standard RMT:
  Offset 0-1:   $FFFF (magic)
  Offset 2:     Version
  Offset 3:     Flags
  Offset 6:     Num samples
  Offset 7:     Num instruments
  Offset 8:     Channels (1-4)
  Offset 9+:    Instrument tables, pattern data, ecc.

Tool rmt2cbm64.py:
  • Legge file RMT binario
  • Genera ca65 assembly con .rodata
  • Esporta _rmt_song_data symbol per C linkage
